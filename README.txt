紐約花蓮慈惠堂　線上點燈和法會報名系統

檔案
  index.html   報名頁（網址首頁）：點燈報名、法會報名、繳費單
  admin.html   後台（網址 /admin）：搜尋、收款、密碼設定
  vercel.json  讓網址不用加 .html

目前狀態：示範版
  - 報名資料只存在填寫者自己的瀏覽器，堂裡收不到。
  - 後台示範帳號：管理員 PIN 8888、王師姐 PIN 1234、李師兄 PIN 5678。
  - 接上堂裡的 Google 試算表後，才會正式收資料。

後台帳號
  每位義工點選自己的名字、輸入自己的 PIN 碼登入。
  收款（標記已繳清／改回未繳費）會記錄經手人和時間。
  負責人／堂主在「設定 → 義工帳號」新增義工、重設 PIN 碼、停用帳號。

開放哪些報名項目
  用負責人／堂主帳號登入後台 → 右上角「設定」→「報名項目設定」
  - 點燈報名：開放報名／暫停
  - 法會場次：開放報名／暫停（報名頁顯示灰色按鈕）／不顯示；可新增場次、填日期

其他設定（在 index.html 最上面的 CONFIG）
  價格、燈種、電話
